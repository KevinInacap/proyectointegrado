# Frontend Design Skill

This skill guides the creation of high-craft, professional web interfaces that avoid generic templates and AI clichés.

## Design Philosophy & Identity
1. **Purpose-Driven Visual Identity**: Design specifically for the subject domain (e.g. municipal public service, social assistance, institutional governance) rather than generic SaaS dashboards.
2. **Harmonious Token System**:
   - Primary: Institutional Navy / Municipal Slate (`#1b365d`, `#0f2347`)
   - Accent: Warm Ochre / Papaya / Emerald (`#059669`, `#d97706`, `#e11d48`)
   - Surface: Glassmorphic layers, elevated borders (`rgba(255,255,255,0.85)` / `border: 1px solid rgba(226, 232, 240, 0.8)`)
   - Dark Mode & Contrast: High-legibility typography matching WCAG AA standards.
3. **Typography with Hierarchy**: Pair crisp geometric or clean grotesque typefaces (e.g., Plus Jakarta Sans, Inter, Outfit) with strict scale hierarchy (xs: 11px, sm: 13px, base: 14px, lg: 16px, xl: 20px, 2xl: 26px).
4. **Information Architecture**: Structure content with clear data density, purposeful badges, status pills, and direct actionable tools.
5. **Micro-Interactions**: Follow Emil Kowalski's guidelines — button `:active` scales (0.97), entry transitions from scale(0.95) + opacity(0), and snappy curves (`cubic-bezier(0.23, 1, 0.32, 1)`).
